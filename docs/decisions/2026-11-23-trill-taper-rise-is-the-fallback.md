# trill-taper-rise is the safe fallback; trill-taper, -glide and -glide-grain15 go to the room

Status: decided (owner 2026-11-22: the question for the night "which will be our safe fallback", "the others need to
run in the room before narrowing further"; 2026-11-23 morning, on the result: "Yes")
Date: 2026-11-23
Amends: decisions/2026-11-19-trill-only-judged-at-the-tryout.md (point 3: the backup was `trillrise`)

## Decision

1. The safe fallback is the preset `trill-taper-rise`: the tapering trill (decisions/2026-11-20-trill-taper-and-the-
   12-ms-island.md), then the plain 4-bin rise, the shape check and the 20 ms longest-stretch rule as the rise presets
   set them. It replaces `trillrise` as the backup switched to by radio when a call answers the room too often.
2. Three calls stay open and run in the installation room before the choice narrows: `trill-taper`,
   `trill-taper-glide`, `trill-taper-glide-grain15` (the owner's favourite sound, its grain at 15 %).

## Why

Three nights on the line R1 - E2 - E4 - E3, 1 m apart, the same 15 pitches, every node playing while the others
listen (bench/sessions/2026-11-20-line-map-trill-taper, 2026-11-21-line-map-trill-taper,
2026-11-22-line-map-trill-taper). Heard between the E nodes (R1, the prototype, read apart):

| Preset | 1 m | 2 m | Loud noise, false calls in 20 min, four nodes |
|---|---|---|---|
| trill-taper-rise, 11-21 / 11-22 | 99 / 96 % | 93 / 99 % | 0 / 0 |
| trill-taper | 95-98 % | 90-96 % | 16 (11-20) |
| trill-taper-glide-riseclear, 11-22 | 92 % | 83 % | 0 |
| trill-taper-glide, 11-21 / 11-22 | 94 / 97 % | 86 / 83 % | not run |
| trill-taper-glide-grain15, 11-21 / 11-22 | 91 / 92 % | 81 / 84 % | not run |

- trill-taper-rise hears as well as trill-taper alone and lets nothing through in the loud noise, on two nights.
- The glide costs 10-15 points at 2 m with or without an ending; the ending adds the noise rejection, not hearing.
- Every map repeated within about 6 points across nights.

## Rules out

- `trillrise` and cricket as the backup: neither ran on the line; trill-taper-rise did, three times measured.
- Narrowing between the three open calls on the desk.

## Revisit when

The room shows trill-taper-rise answering the room (false calls counted in the radio log) or missing calls the open
calls hear; or a sound change to the taper or the rise.
