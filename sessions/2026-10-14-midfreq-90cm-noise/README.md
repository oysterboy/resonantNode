# 2026-10-14 DET-012: speech and music false answers at 2,800 and 2,600 Hz (DC blocker, 90 cm, up, 0.5 FS, Scalar)

Same setup as 2026-10-14-lowfreq-90cm-noise (E2 Analyzer, code bfbe0c8, radio 50 cm from E2, full
volume, 90 deg to the mic; drum and bass, then WDR5 speech; 50 windows each). Two earlier attempts at
the music run were cancelled during ad breaks and are not in this folder.

| Frequency | Speech valid | Music valid |
|---|---|---|
| 3,200 Hz (2026-10-14-dc-90cm-noise) | 0 | 0 |
| 2,800 Hz | 4 | 1 |
| 2,600 Hz | 3 | 4 |
| 2,000 Hz (lowfreq-90cm-noise) | 3 | 4 |
| 1,500 Hz | 1 | 30 |

False answers appear as soon as the frequency drops below 3,200 Hz, with no clean middle ground at
2,600-2,800 Hz. One 100 s run per cell, different radio content per run, so counts of 1-4 are not
ordered reliably; the step from 0 (3,200 Hz) to a few per 50 windows is the finding.
